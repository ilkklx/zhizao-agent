# 智造实演 · AGV 仓储小车避障实验教学智能体

面向中学信息科技 / 通用技术课堂的**教学智能体**：学生用自然语言指挥 AGV 仓储小车（如"往右走 3 步"），智能体经**意图识别 → 参数提取 → 工作流编排**，由代码节点运行 **A\* 算法**规划避障路径，最后以**交互卡片**（路径动画 + 折线图）把结果交还给学生。

- 比赛作品：2026 年广东省"元智新潮"大学生智能体应用创新大赛
- 构建平台：腾讯云智能体平台（标准导出包，含组件哈希，可回导平台）
- 仓库内容：平台导出原件 + 解包后的智能体配置 / 工作流 / 知识库 + 设计说明书

## 核心设计

**1. 意图路由（教学与操作分离）**
> "如果用户询问传感器原理、AGV 安全规则、算法概念、课程知识等学习类问题，请直接使用知识库问答回答，不要调用工作流；只有用户明确要求规划路径……才调用工作流。"（agent_config.json 路由指令原文）

**2. 31 节点工作流**（42 条边）
`开始 → 参数提取 → 条件判断阶梯（任务书/选传感器/参数调试/运行/下一步/上一步/重置/问答）→ A* 代码节点 → 动画渲染代码节点 → 交互卡片 → 结束`；知识问答分支走意图识别 → 知识库。

**3. 三传感器避障设计**：红外（膨胀 0.5 格）、超声波（膨胀 2.0 格、半径 1）、激光雷达（膨胀 3.0 格、半径 2）——换传感器即换安全距离，直观对应教材知识点。

**4. 六个交互卡片**：任务书、参数调试（默认 10×10 地图、障碍 [[2,1],[3,0],[5,5]]）、选传感器、地图搭建、路径动画、折线图（演示 (0,0)→(4,4) 共 8 步）。

**5. 教学知识库**（4 篇）：AGV 安全规范要点（GB/T 45750-2025）、传感器知识（三类对比 + 膨胀半径映射）、课标要点（义教 2022 + 高中 2017 算法与人工智能）、教材算法与 AI 要点（A\* 启发式搜索）。

## 使用方式

- **重新导入平台**：使用平台"导入应用包"功能选择 `原始包/智造实演_v20260908092446_package.zip`（回导未在本机实测，平台入口以平台文档为准）；
- **直接阅读/二次开发**：看 `智造实演-智能体设计说明书.md` 了解设计全貌；工作流定义在 `app/workflow/workflow_*.json`（JSON 节点图，含参数提取约束与 A\* 代码节点源码）；人设与路由指令在 `app/agent/agent_config.json`。
